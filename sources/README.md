# 原始來源區（舊結構）

新來源請一律保存於 [`raw/`](../raw/)，不要再放入本目錄。本目錄是初始架構留下的相容說明，避免舊連結失效。

原始來源視為不可變資料：不要在檔案內覆蓋、刪除或修正文句；有新版就新增檔案，並在 `wiki/source-notes/` 說明差異。

## 分類

- `inbox/`：尚未由 LLM 處理的來源。
- `articles/`：新聞、專訪、網路文章與公開文字資料。
- `filings/`：監管申報、年報、季報、法說簡報與逐字稿。
- `research-reports/`：券商、研究機構與產業報告。
- `market-data/`：價格、成交量、指數、財務指標與其他資料快照。
- `datasets/`：可重現分析使用的 CSV、JSON 或其他資料集。
- `assets/`：PDF 附件、圖片與其他媒體。

檔名建議以 `YYYY-MM-DD-來源或公司-主題` 開頭，並保留原始網址、發布時間與資料截至日。不要只依檔名推斷資料日期。
