# 原始資料區

`raw/` 是本 Wiki 的不可變來源區。以後貼入的文章、PDF、財報、研究報告與資料快照，預設先保存於這裡，再由 LLM 建立來源筆記、更新 Wiki 與索引。

## 分類

- `inbox/`：尚未處理的來源。
- `articles/`：新聞、月刊、專訪與網路文章。
- `filings/`：年報、季報、法說簡報與監管申報。
- `research-reports/`：券商、研究機構與產業報告。
- `market-data/`：價格、成交量、指數與財務資料快照。
- `datasets/`：可重現分析使用的資料集。
- `assets/`：來源圖片、PDF 附件與其他媒體。

原始檔案不得覆蓋、刪除或改寫。新版或更正版本請新增檔案，並在 `wiki/source-notes/` 記錄差異。
