# HTML 簡報

保存由 `notes/` 與 `slides/` 衍生的 HTML 簡報。優先使用內嵌 CSS 與本地連結，讓檔案可以離線開啟；引用與資料截至日要保留在最後一頁。

## 簡報清單

- `taiwan-stock-market.html`：臺灣集中市場
- `ai-stock-bubble.html`：AI 股市泡沫
- `fed-and-stocks.html`：聯準會與股市
- `esg-stock-performance.html`：ESG 股票績效（資料待建立狀態）

共用視覺樣式與翻頁控制放在 `deck.css`、`deck.js`；新增簡報時沿用相同結構，並在根目錄首頁加入入口卡片。
